# Mobile assets

- `brand/`: canonical DABBOBA wordmark used by splash and app surfaces.
- `icons/`: install icon and in-app navigation/action icons.
- `draw/gacha/`: gacha machine, capsule atlas and glow textures.
- `draw/kuji/`: kuji ticket presentation layers.
- `fonts/`: bundled licensed font files and their license text.

Product and IP photos do not belong in this directory. Upload those through the
operator media flow so the API can return managed-storage URLs.
