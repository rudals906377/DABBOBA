# DABBOBA 가챠·쿠지 직접 조작형 시안

현재 앱의 캡슐·티켓 디자인을 유지하면서 낙하, 개봉, 종이 휘어짐과 소리를 비교하는 **로컬 브라우저 미리보기**입니다. 실제 앱 화면을 교체하지 않으며 결제·추첨·상품·재고 API에 연결하지 않습니다. 힉스필드나 외부 생성 서비스를 사용하지 않았습니다.

이번 변경은 **쿠지 내부를 인쇄된 아이보리 당첨권처럼 정리**하는 작업입니다. 원본 주황색 티켓·말림·카메라·개봉 속도·소리는 유지하고, 원래 절취 모양에 맞는 얇은 안감과 작은 원본 워드마크 인쇄를 넣었습니다. 사진의 색을 보정하거나 잘라내지 않고, 상품명과 고지문을 짙은 잉크색으로 바꿨습니다. 접힌 경계의 빛만 안감에 어울리는 따뜻한 색으로 조정했으며 강도·지속시간은 유지합니다. 가챠의 기존 4.2초 연출과 앞면 이음새 보정도 그대로입니다.

최신 외곽 정리: 바깥 검은 간격을 본체와 이어지는 주황색으로 채우고, 두꺼운 갈색 외곽선을 얇은 짙은 주황색 선으로 줄였습니다. 카드 아래쪽에만 얕은 두께 음영을 넣어 한 장의 종이처럼 보이게 했습니다. 이 바탕은 테두리만 채우는 구조이므로 위에서 설명한 아이보리 내부·원본 인쇄·말림과 개봉 속도는 유지합니다.

## 실행

```sh
cd videos/dabboba-draw-preview # 저장소 루트에서 실행
npm run preview
```

미리보기: <http://127.0.0.1:4195/>

Git에는 실행 소스·로컬 자산·테스트·비교용 이전 소스(`proof/*.mjs`)를 포함합니다. 테스트가 만드는 캡처·JSON 보고서와 `snapshots/`는 로컬 검증 결과로 보존하되 추적하지 않습니다. 검증 결과 요약과 범위는 `QA.md`에 기록합니다.

서버는 로컬 컴퓨터의 `127.0.0.1`에만 연결됩니다. 위 명령은 백그라운드 미리보기를 실행합니다. 브라우저의 네트워크 주소를 외부에 공개하거나 배포하는 명령이 아닙니다. 이 시안 폴더에 포함된 JS·이미지·폰트·WAV를 사용합니다.

```sh
npm run test
```

전체 테스트는 미리보기 서버가 실행된 상태와 저장소의 Playwright 테스트 의존성이 필요합니다. 브라우저를 열지 않는 모션·음향 생명주기·자산·재질 검증만 실행하려면 다음 명령을 사용합니다. 이 파일들은 Node.js 기본 테스트 실행기만 사용합니다.

```sh
node --test tests/assets.test.mjs tests/audio.test.mjs tests/motion.test.mjs tests/capsule-material.test.mjs tests/kuji-scene.test.mjs tests/kuji-result-layout.test.mjs
```

브라우저 전체 검수는 다른 검수 세션과 동시에 실행하지 않습니다. 검증 범위와 남은 항목은 [QA.md](./QA.md)에 기록합니다.

## 조작

- `가챠 / 쿠지`를 전환해 각각 확인합니다.
- 가챠는 재생 버튼으로 시작하고, 다시 보기로 반복할 수 있습니다.
- 가챠 재생 중 `결과 바로 보기`를 누르면 진행 중인 애니메이션 프레임과 소리를 취소하고 같은 고정 예시 상품을 바로 보여줍니다. 실제 추첨을 수행하는 버튼이 아닙니다.
- 쿠지는 종이를 오른쪽으로 직접 당깁니다. 손을 되돌리면 접힘도 되돌아가며, 덜 열린 상태에서 다시 잡으면 그 위치부터 이어집니다. 버튼·키보드 대체 조작도 제공합니다. 완료 구간이 짧아 쿠지에는 건너뛰기를 추가하지 않습니다.
- 소리는 처음에는 꺼져 있습니다. 소리 버튼을 직접 눌러야 켜집니다.
- 초기화·장면 전환·음소거·브라우저 숨김·결과 바로 보기 시 재생 중이거나 예약된 소리를 중단합니다.
- 동작 줄이기 설정에서는 낙하·개봉·종이 움직임을 생략하고 결과 영역으로 넘어갑니다.

## 연출 기준

### 가챠 — 4.2초

| 구간 | 동작 |
| --- | --- |
| 0–0.50초 | 배출구에서 트레이로 낙하 |
| 0.50–0.89초 | 같은 반지름의 0.30배 높이로 첫 번째 반동을 더 천천히 |
| 0.89–1.10초 | 같은 반지름의 0.08배 높이로 더 작게 튀고 마지막 착지 |
| 1.10–1.20초 | 잔떨림이 가라앉으며 잠깐 정지 |
| 1.20–1.80초 | 같은 구도·경로로 줌인을 0.60초 동안 진행, 캡슐만 남음 |
| 1.76–3.30초 | 이음새와 뚜껑이 동일한 3차 완화 곡선으로 연속 개봉, 확대의 마지막 40ms와 미세하게 겹침 |
| 1.80초 | 기존 이음새 소리 재생, 음원·음량 그대로 유지 |
| 1.80–3.50초 | 내부 빛을 더 일찍 쌓되 최대 강도 0.78 유지 |
| 3.12–4.00초 | 기존 내부광 확산을 앞 구간으로 분산; 약 3.713초에 화면 모서리까지 순백이 됨 |
| 3.82–4.06초 | 약 0.107초의 순백 대기 뒤 고정 예시 상품 공개 |
| 4.06–4.20초 | 결과를 안정적으로 유지하며 재생 완료 |

두 번의 바운스는 이전 4.0초 단계에서 총 0.49초에서 0.60초로 조정한 상태를 유지합니다. 이번에는 바운스·낙하·반동 높이를 다시 바꾸지 않습니다.

원래의 8비트 기계·UI와 앱의 원본 캡슐 셰이더를 바탕으로 합니다. 이전 승인에 따라 상단 돔·테두리·안쪽·반사광의 초록 기운을 제거하고, 하이라이트를 부드럽게 낮춰 얇은 아이보리 플라스틱 인상을 더했습니다. 실제 투과·굴절을 계산하는 재질은 아닙니다. 원래의 얇은 원형, 하단 초록색과 인쇄 로고는 유지합니다. 개봉 시 껍질별 분리 오프셋은 0.32이며, 안쪽 빛은 중심이 밝고 테두리 쪽이 어두워지는 깊이 차이가 있습니다. 이 형태·재질·분리 폭은 이번 연결감 보완에서 변경하지 않습니다.

확대 마지막 40ms에 아주 작은 개봉을 겹쳐 확대 뒤 멈춘 느낌을 줄입니다. 이음새가 짧게 먼저 벌어졌다가 느려지는 구간 없이 뚜껑과 같은 진행률로 움직입니다. 개봉할 때 내부에서 시작한 빛이 틈과 주변으로 퍼지고, 기존보다 일찍 흰 배경으로 연결됩니다. 상품은 화면 전체가 순백이 된 뒤 약 0.1초 후 등장합니다. 캡슐은 같은 카메라 경로를 따르며 앞으로 날아오지 않습니다. 착지 그림자는 접촉에서 진해지고 반동에서 약해지며 확대가 끝나면 사라집니다. 최대 밝기·원본 재질·분리 폭은 유지합니다.

화면에 전혀 보이지 않는 완전 투명 단계는 그리기를 생략하고, 입력값이 같으면 캡슐 렌더링 아틀라스를 재사용합니다. 해상도·원화·카메라·재질은 바꾸지 않습니다. 이 구현 설명은 프레임률 개선이나 최신 GPU 검수 완료를 뜻하지 않습니다.

가챠 결과 이미지는 로컬 `assets/products/sample-maomao.png`에 있는 **고정 마오마오 예시**입니다. `시안 예시 · 실제 당첨 아님`을 함께 표시하며, 매번 같은 이미지가 나옵니다. 실제 당첨 결과·상품 등급·고객 데이터와 연결하지 않습니다.

### 쿠지 — 드래그 + 남은 길이에 따른 짧은 마무리

이전 단계에서 정리한 평면 앞면의 이음새를 유지합니다. 이번에는 놓는 순간의 속도 연결과 카드 내부 결과 배치를 다듬습니다.

- 원본 외곽과 앞면 텍스처를 **1517×1037 크기로 먼저 합성한 뒤 한 번에 필터링**합니다. 두 투명 레이어를 따로 필터링할 때 경계의 합산 덮임이 75%에 그쳐 어둡게 보이는 이음새를 정리하기 위한 처리입니다. 이미 떠오른 종이는 기존 투명도·재질을 그대로 사용합니다.
- 보정은 원래 종이가 덮는 범위 안에서만 적용합니다. 투명한 여백까지 새 면을 만들지 않으므로 주황색 고정 테두리는 종이를 따라 들리지 않습니다.
- 원본 PNG·로고·색·이중 인쇄 테두리·화살표·바코드를 고치거나 덧그리지 않습니다. 카메라·말리는 곡면·광량·소리도 변경하지 않습니다. 최신 시각·회귀 검증 완료 여부는 이 사양과 별도로 기록합니다.
- 드래그 첫 이동부터 종이가 휘어지며 뒷면과 접힘 그림자가 보입니다.
- 부분적으로 열린 종이를 다시 잡으면 `현재 진행률 + 새 이동거리 / 너비`로 이어가며 처음 위치로 튀지 않습니다.
- 너비의 **58% 이상** 당기면 개봉합니다.
- **18% 이상 + 오른쪽 650px/s 이상**의 빠른 당김도 개봉합니다.
- 기준 미달·취소 시 **180ms** 동안 닫힌 상태로 복귀합니다.
- 개봉 확정 뒤 시간은 `0.36 + 0.36 × (1 − 시작 진행률)`초로, **최대 720ms**입니다. 더 많이 당긴 상태일수록 빨리 끝납니다.
- 놓을 때의 오른쪽 속도를 정규화해 단조 5차 Hermite 곡선의 시작 속도로 사용합니다. 멈췄다가 놓으면 정지에서 부드럽게 가속하고, 빠르게 놓으면 그 속도를 제한 범위 안에서 이어받습니다. 역방향 속도는 개봉을 거꾸로 돌리지 않습니다.
- 벗김은 완료시간보다 240ms 앞서 감속하며 마무리됩니다. 접힌 종이 정리는 그 시점의 60ms 전부터 140ms 후까지, 결과 공개는 그 시점부터 200ms 후까지 겹쳐 진행합니다.
- 원래 주황색 앞면·카메라·종이 휘어짐 형태는 유지합니다. 종이 뒷면의 미세한 결·넓은 명암만 다듬고, 개봉 경계의 빛을 세로 중앙에 맞춥니다.
- **고정 초콜릿 토끼·티아라 예시 이미지와 짧은 이름**을 원래의 주황색 티켓 틀 안쪽에 표시합니다. `시안 예시 · 실제 당첨 아님`을 함께 표시하며 실제 당첨 데이터는 사용하지 않습니다.
- 결과 영역만 가로 80%·세로 76%로 넓히고 사진 열을 48%로 조정해 예시 사진을 약 24% 키웠습니다. 상품명 두 줄과 원본 빈 공간 안쪽 안전 여백을 유지하며, 아주 작은 화면에서는 이름 13px·가로 간격 10px를 사용합니다.
- 쿠지 표면 이미지는 원본 두 레이어를 그대로 사용합니다. 기존 마찰·찢김 소리도 변경하지 않습니다.

캡처용 자동 시연은 0.90초에 65%까지 당긴 뒤 486ms 동안 마무리해 1.386초에 완료하고, 1.62초까지 결과를 유지합니다. 직접 조작할 때는 사용자가 놓은 진행률에 따라 마무리 시간이 달라집니다.

## 원본 보존과 소리

`scenes/capsule-shader.mjs`는 앱의 `gacha-capsule-3d-shaders.ts`를 수정 없이 복사한 파일입니다. 캡슐 기계, 쿠지 외피·벗김 레이어, 공식 워드마크와 두 가챠 WAV 역시 원본과 바이트 단위로 같습니다. `tests/assets.test.mjs`가 현재 원본과 SHA-256을 비교합니다. 이 테스트가 실패하면 원본을 임의로 덮어쓰지 말고 차이를 확인해야 합니다.

`scenes/capsule-material.mjs`는 원본 파일을 그대로 보존한 채 상단 아이보리 재질을 파생합니다. 재질 파생본은 원래 교차 계산·두께와 하단 재질 수식을 유지하며, 최종 시안 파생본에서만 개봉 오프셋 0.32와 내부광 깊이 그라데이션을 추가합니다. 해당 변형은 미리보기에만 적용되며 실제 앱의 캡슐을 변경하지 않습니다.

가챠 낙하 원음의 첫 충격 0.14초만 메모리에서 잘라 기존과 같은 0.50·0.89·1.10초의 세 번 접촉에 맞춥니다. 소리는 기존과 같은 0.54 → 0.17 → 0.07로 점차 작아지며, 발췌 길이가 접촉 사이보다 짧아 겹치지 않습니다. 이음새 소리는 기존 1.80초를 유지합니다. 이 시점들은 움직임과 공유하는 상수에서 가져오며 원음·음량·필터와 원본 WAV는 변경하지 않습니다. **쿠지의 마찰·찢김 소리는 고정 시드로 로컬 합성한 시안용 소리**이며 실제 녹음된 종이 폴리로 주장하지 않습니다. 배경음악은 없습니다.

예시 상품 이미지는 `/Users/kyoungmin/Desktop/DBB/상품사진/가챠/500엔/약사의 혼잣말 무규토/마오마오2.png`를 수정 없이 복사한 것이며, 원본과 바이트 동일성을 확인했습니다. 캡슐·티켓에 상품 이미지를 합성한 것이 아니라 독립된 결과 화면 요소로 사용합니다.

쿠지의 `assets/products/sample-kuji-rabbit.jpeg`도 `/Users/kyoungmin/Desktop/DBB/상품사진/가챠/실바니안 어드벤쳐 시리즈/아기 초콜릿 토끼와 티아라.jpeg`를 수정 없이 복사한 고정 예시이며, 원본과 바이트 동일성을 확인했습니다. 두 예시 모두 무작위 선택이나 실제 상품 지급과 연결하지 않습니다.
