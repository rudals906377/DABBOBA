## 결정적 캡처와 소스 보호

- 이번 `node check-captures.mjs kuji`가 통과했습니다. 쿠지 1.62초·모션 샘플 34개, 런타임·레이아웃·동작·텍스트 대비 오류 0건입니다. 가챠 캡처는 직전 수정에서 4.2초·85개 샘플로 통과했고 이번에는 가챠 코드를 변경하지 않아 재실행하지 않았습니다(가챠 브라우저 회귀는 이번에도 통과). 각 `check.json`의 `snapshots.files`가 해당 실행의 유효 스냅샷 목록이며 이전 캡처 파일은 역사 기록입니다.
- 각 장면의 단일 클립에 하위 요소가 있다는 구조 권고 1건은 남겨 둡니다. 짧은 한 장면이므로 별도 하위 장면으로 쪼개지 않았습니다.
- 5.9MB 원본 Noto Sans KR 폰트는 HTML에 인라인되지 않습니다. 로컬 폰트 파일은 정상 제공되지만, HTML 한 파일만으로 독립 실행한다고 주장하지 않습니다.
- 가챠 확대/개봉, 흰 배경 결과, 쿠지 원본/말림/내부 결과를 실제 인앱 브라우저와 프레임 캡처에서 확인했습니다. 증거는 `proof/`에 있습니다.
- Canvas 내부 상태는 정적 DOM 키프레임으로 추출되지 않습니다. `keyframes --ghost`의 합성 결과는 마지막 흰 화면만 보이므로 유효한 모션 증거로 사용하지 않고 `proof/diagnostics/`에 구분했습니다. 동작은 순수 모션 테스트·실제 입력 테스트·개별 프레임으로 검증했습니다.
- 최신 키프레임 진단도 Canvas 내부 요소 수를 0으로 보고합니다. 1.10–2.36초 집중 진단은 `proof/diagnostics/gacha-3.1-closeup-ghost.png`에 별도 보존했으며, 개별 프레임·GPU 픽셀 검사와 브라우저 상태 검증을 주된 증거로 사용합니다.
- 이전 4초 가챠의 1.60–3.10초 개봉 진단은 `proof/diagnostics/gacha-4.0-open-ghost.png`에 보존했습니다. Canvas 내부 요소 0 보고는 동일하며, 결과를 실제 프레임과 함께 확인했습니다.
- 이전 4.2초 가챠의 확대 구간 1.20–1.80초 진단은 `proof/diagnostics/gacha-polish-ghost.png`에 유지합니다. 이번 1.86–3.30초 연속 개봉 진단은 `proof/diagnostics/gacha-smooth-open-ghost.png`이며, Canvas 내부 요소 0 한계는 같습니다. 개별 2.58초 프레임·합성 분리 속도 검사·GPU 픽셀 비교와 함께 확인했습니다. 기존 재질·형태·최종 구도를 보존했고 캡슐 잘림이 없습니다.
