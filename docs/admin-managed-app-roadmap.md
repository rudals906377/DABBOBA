# 앱 운영 항목의 관리자 관리 확장

기준일: 2026-09-09. 사용자 결정: 앱에 관한 운영 항목은 가능한 한 관리자 페이지에서 수정할 수 있도록 단계적으로 확장한다. 이 문서는 전체 기능의 구현 완료나 운영 적용을 의미하지 않는다.

## 범위와 원칙

- 고객 앱의 확정된 디자인·탭 순서·가챠 연출은 유지한다. 먼저 자주 바뀌는 콘텐츠와 운영 정책을 설정으로 분리한다.
- 관리 화면은 `apps/admin`에서 기존 인증된 관리 API를 호출한다. 관리자 브라우저나 고객 앱에 DB 비밀키를 주지 않는다.
- 서버가 권한, 입력, 변경 사유, 중복 요청, 낡은 버전 충돌과 감사 이력을 검증한다. 버튼 숨김은 접근 통제의 대체가 아니다.
- 임의 JSON·HTML·스크립트·SQL 편집기로 모든 것을 열지 않는다. 허용된 항목별 폼과 명시적 타입/범위 검증을 제공한다.
- 결제 확정, 잔액·재고 원장, 이미 확정된 추첨 결과, 인증 검증, 감사 기록은 일반 설정으로 수정하거나 우회할 수 없다. 정정은 별도 권한이 있는 업무 흐름과 이력으로 처리한다.
- Supabase 전환 중에도 관리 API 소비 계약과 고객 데이터는 보존한다. 전환 계획은 `supabase-only-transition.md`를 따른다. 운영 배포·유료 설정·실제 발송·결제는 별도 승인과 실환경 검증이 필요하다.

표의 “기존 기반”은 코드 확인 결과다. 실제 운영자 로그인, 운영 DB 저장, 실제 기기 반영 및 운영 배포가 완료됐다는 뜻은 아니다.

## 1단계: 홈 구성

- 관리 주소: `/catalog/home-sections` (이번 단계 코드 구현 완료, 실계정 저장·운영 적용 미검증).
- 기존 API: `GET/POST /v1/admin/home-sections`, `PATCH /v1/admin/home-sections/{sectionId}`.
- 기존 고객 API: `GET /v1/catalog/home-sections`.
- 기존 권한: 조회 `catalog.read`, 생성/수정 `catalog.write`. 관리 UI의 `catalog.manage`는 둘 다 요구한다.
- 제목, 등록된 IP, 0 이상의 정렬 순서, 노출 여부를 관리한다. 같은 순서는 서버가 섹션 ID로 정렬한다.
- 새 항목은 비노출을 기본으로 한다. 물리 삭제 대신 비노출로 되돌릴 수 있다.
- **최초 섹션을 저장하면 자동 IP 컬렉션에서 관리자 구성으로 전환된다.** 비노출 항목만 있으면 작품별 묶음은 표시되지 않는다. 오늘의 뽀바 가챠·쿠지 구분은 별개이므로 유지된다. 최초 저장 전 이 영향을 명시적으로 안내한다.
- 활성 섹션이라도 IP가 비활성이거나 표시 가능한 상품이 없으면 고객에게 나타나지 않는다. 현재 대상 상품은 활성 가챠·쿠지 판매 상품이며 경품 전용 SKU는 제외한다. IP별 최대 20개를 최신순으로 가져오는 기존 계약은 변경하지 않는다.
- 관리자 저장과 고객 앱 실시간 반영은 다르다. 앱이 홈을 다시 불러오거나 새로고침할 때 최신 값을 읽는다. 오프라인에서는 기존 캐시가 보일 수 있다.
- 변경 사유·중복 방지 키·기존 버전을 전달한다. API 오류나 충돌은 저장 성공으로 표시하지 않는다.

## 이후 설정을 추가할 때의 완료 조건

1. 설정의 소유자, 허용 값, 권한, 기본값과 적용 시점을 먼저 확정한다.
2. DB 제약과 트랜잭션, 변경 이력, 버전 충돌, 재시도 안전성을 구현한다.
3. 공개 조회에는 고객에게 필요한 값만 포함한다. 관리자 전용 정보와 비밀키는 제외한다.
4. 앱의 기존 화면과 서버의 실제 업무 규칙이 같은 버전을 사용하도록 연결한다. 숨김만으로 판매 차단을 대신하지 않는다.
5. 조회 실패/오프라인/구버전 앱에 대한 기본값과 복구를 정의한다. 점검·판매 차단처럼 안전과 관련된 설정은 오래된 클라이언트 값으로 서버 검증을 우회하지 못하게 한다.
6. 정상 변경, 권한 없음, 잘못된 입력, 동시 수정, 중복 요청, 되돌리기와 고객 반영을 검증한다.
7. 코드 검증, 로컬 관리 화면 저장, 실물 기기 확인, 운영 배포를 구분해 보고한다.

다음 단계는 이 목록에서 하나씩 범위를 정해 진행한다. 이 문서 자체가 모든 설정 기능의 즉시 구현 또는 운영 적용 승인은 아니다.
