# DABBOBA 출시 준비 5개 항목 — 2026-09-30 읽기 전용 점검

이 문서는 친구 명의 **운영 Supabase `rconfxsykttfvznakile`**와 공개 API를 조회한 시점의 증거다. 테스트 DB, 로컬 단위 테스트, 공개 URL의 200 응답은 운영 결제·실기기·스토어 심사 완료를 뜻하지 않는다. 이 점검에서 운영 데이터, 결제 설정, 판매 상태, 계정, 비밀키는 변경하지 않았다.

## 1. 회원탈퇴와 로그인

- 운영 DB 집계: 완료된 탈퇴 요청 1건, 미완료 요청 0건, 외부 인증 삭제 대기 작업 0건, 보관 중인 Apple 갱신 토큰 암호문 1건. 완료 1건은 앞서 승인된 Google 테스트 계정의 삭제이며 Apple 토큰 폐기 실증은 아니다.
- Apple 탈퇴 작업은 Apple `/auth/revoke`가 HTTP 200을 반환한 뒤에만 Supabase Auth 삭제로 진행한다. Apple 문서상 200은 새로 폐기됐거나 이미 무효인 토큰을 뜻한다. 400/연결 실패는 재시도 대상으로 남겨야 한다. 오류 시 Auth를 삭제하지 않고 토큰을 로그에 남기지 않는 회귀 테스트를 추가했다.
- 실제 Apple 폐기 증거에는 **탈퇴가 허용된 별도 Apple 테스트 회원**의 요청 접수 → 작업의 `apple_revoked_at` 기록 → Supabase Auth 삭제 → 로컬 익명화 → 재로그인 차단 확인이 필요하다. 현재 Apple 회원을 임의로 탈퇴시키지 않는다.
- 운영 공개 로그인 수단은 `KAKAO`, `NAVER`, `GOOGLE`, `APPLE`; `PHONE`은 없다. 휴대폰 로그인을 출시 범위에 넣는다면 친구 명의 SMS 발신/과금 설정, OTP 남용 방지, WD iPhone과 Android 실기기에서 가입·재로그인·로그아웃·탈퇴 시험이 별도 필요하다. SMS 계약과 유료 발송은 이 점검에서 시작하지 않았다.

## 4. 스토어·정책

- `https://dabboba.net/privacy`, `/terms`, `/support`, `/account-deletion`은 인증 없이 HTTPS 200이었다. 내용의 법률 적합성·실제 사업자 표시·고객지원 응답을 증명하는 것은 아니다.

- 공개 LIVE 모바일 릴리스 검사에는 후보 빌드 환경값이 제공되지 않았고 서버가 `PRELAUNCH`라 통과하지 못했다. 서명된 최신 iOS/Android 출시 빌드, 실기기 결제 복귀, 스크린샷, 심사 계정, 데이터 수집 선언은 별도로 남았다.

[Apple의 계정 삭제 안내](https://developer.apple.com/support/offering-account-deletion-in-your-app)는 Sign in with Apple 토큰 폐기를 요구한다.
