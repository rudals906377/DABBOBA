# 출시 전 돈·탈퇴 경로 점검 (2026-10-06)

돈이 움직이는 경로를 네 영역으로 나눠 코드를 다시 읽었다: 결제·주문, 환불, 뽑기·보관·포인트·교환, 탈퇴. 아래는 확인된 문제와 처리 상태다.

이중 결제, 이중 환불, 결제 금액보다 큰 환불, 다른 계정 삭제 같은 문제는 나오지 않았다. 각 영역에서 확인한 부분은 다음과 같다.

- 결제·주문
  - 주문 멱등성
  - 결제사 이벤트 중복 제거
  - 서버 가격 재계산
  - PortOne 금액·채널·결제수단 검증
- 환불
  - 부분 환불 산정식
  - 포인트 1회 복원
  - 전액·부분 환불 상호 배제
- 뽑기
  - 뽑기 확정 잠금과 결과 재생
  - 남은 수량 비례 확률
  - 포인트 환급 적격 조건

## 오늘 고친 것

| 영역 | 문제 | 결과 |
|---|---|---|
| 결제 | 결제 확인 전에 이상 상태·금액 불일치·부분 취소 알림이 오면 주문이 검토 상태가 된 채 재고 예약·사용 포인트·배송 보류가 영영 풀리지 않음 | 결제 실패와 같은 방식으로 즉시 풀고 `cancelled_at` 기록. 실제로 돈이 잡혔으면 기존 늦은 결제 환불 경로로 처리 |
| 환불 | 취소 결과를 모르는 전액 환불(시간 초과·KG 거절 포함)이 영구히 `INDETERMINATE`로 남아 주문이 잠김 | 10분 뒤 재조회에서 결제사에 취소가 없으면 다시 처리하거나 중단할 수 있는 상태로 전환 |
| 환불 | 환불 자격 확인과 뽑기가 동시에 일어나면 오래된 수량으로 판단해 주문이 영구히 잠김 | 행을 먼저 잠그고 새 문장에서 수량을 셈 |
| 환불 | 부분 환불 계획이 시간 초과 직후 풀려, 늦게 도착한 카드 부분 취소를 반영하지 못함 | 같은 10분 대기 후에만 해제 |
| 환불 | 오래 걸린 취소 요청의 응답이 500 | 현재 행을 다시 읽어 응답 |
| 탈퇴 | 결제 완료(PAID) 주문이 영구 차단 항목이라 한 번이라도 결제한 고객은 탈퇴 불가(PAID→FULFILLED 전환이 없음) | 미결제·검토 중 주문만 차단. 남은 뽑기권·보관 상품은 원래대로 따로 차단 |
| 탈퇴 | 수락된 교환 제안이 교환 완료 뒤에도 차단 항목으로 남음 | 교환이 진행 중(MATCHED)일 때만 차단 |
| 교환 | 만료 정리 중 동시에 들어온 제안의 상품이 영구히 `EXCHANGE_OFFERED`로 남음 | 닫힌 글에 남은 대기 제안을 새 스냅샷으로 다시 정리(기존에 남은 것도 함께 정리) |
| 교환 | 신고로 글을 숨길 때 철회·거절된 예전 제안의 상품까지 풀어, 다른 글에 제안 중인 상품이 풀림 | 이번에 거절한 제안과 진행 중 교환의 수락 제안만 풀기 |

검증: DB 156, API 412 통과(2 skip), 워커 164 통과(로컬 PostgreSQL 17 전체 실행).
