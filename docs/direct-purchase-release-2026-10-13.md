# 직접 선택 구매 릴리스 준비 — 2026-10-13

## 범위

직접 선택 구매, 기존 가격, 46종 각 20개 초기 재고, 교환방 유지, 포인트 환급 신규 신청/만료 전환 숨김, 쿠지 판매 숨김, NICE·토스 공통 TEST 심사 웹을 한 변경으로 준비한다. 과거 결제·뽑기·재고 기록은 보존하고 PRELAUNCH를 유지한다.

## 검증

- 전체 작업공간 빌드 12개, 타입 검사 20개, 웹/앱 구조 단위 검사 1,203개 통과. 보호 런타임, 스토어 구조, Forge/Glob 검사 통과. 비밀값 패턴 검사에서 의심 경로 없음.
- 임시 PostgreSQL에 전체 100개 마이그레이션 적용. API 통합 검사 52개 전부 통과: 직접 선택 SKU 지급, 재고·주문 복구·교환·환불, 공통 PG 설정/검증, 과거 주문 처리 포함. 실제 PG 응답은 합성이므로 실제 승인 증거가 아니다.
- 제한된 runtime DB 역할의 과거 주문 조회·완료 요청 재시도·소비·복구 검사 통과. 자동 만료 포인트 전환이 닫혀 있고 보존된 원장 함수가 원자적으로 작동하는 별도 새 임시 DB 검사 통과.
- 기존 새 뽑기/쿠지 구매를 전제로 하던 시험은 역사적 주문을 명시적으로 심는 테스트 전용 fixture로 분리했다. 현재 구매 API를 다시 열거나 정책 검사를 우회하지 않았다. 보존된 완료 요청의 멱등 복구는 실제 API로 검증한다. 신규 구매는 DIRECT 통합 검사로 확인한다.
- 현재 약관/운영정책은 0099로, 0065/0090의 이전 증거는 보존한 HTML과 고정 해시로 따로 검증한다.
- 전체 검사에서 기존 이미지 저장소의 본문 지연 시간 제한 검사가 멈추는 현상을 재현했다. 단독 실행은 15초에 통과했고, Web/Edge 숫자 타이머 시험을 별도 프로세스로 격리해 가짜 타이머가 Node 전송 내부와 후속 실제 네트워크 시험에 남지 않도록 수정했다. 운영 저장소 코드는 변경하지 않았다.
