# 포함 상품 구매 복원 및 포트원 심사 전환

최신 사용자 결정은 결제 후 캡슐을 열 때 포함된 상품 중 1개를 지급하는 기존 방식이다. 결제 전에 개별 상품을 지정할 수 없고 중복될 수 있음을 안내하며, 포함 구성·공개 확률·취소 및 법령상 권리는 유지한다. 쿠지는 준비 중이며 판매하지 않는다. 교환방 유지, 신규 포인트 환급 및 보관 만료 자동 포인트 전환 중지는 그대로다.

이지페이와 나이스페이 모두 포트원을 통해 신청한다. 공통 심사 웹은 KICC V2/NICE V2 TEST 채널만 사용하며 저장된 주문의 결제사를 바꾸지 않는다. 토스·이니시스·KCP의 기존 거래 및 서버 조회/복구 코드는 보존한다. 채널 생성·실제 키 연결·승인·LIVE는 이 변경만으로 완료되지 않는다.

0100은 과거 직접 선택 SKU를 비활성/PAUSED로 두되 재고·예약·거래를 삭제하거나 이동하지 않는다. 0093~0099는 변경하지 않는다. 기존 직접 구매 주문의 불변 지급/환불 및 적격 교환은 유지한다. 2026-10-13 직접 구매 정책 HTML은 legal-history에 보존하고 새 2026-10-13-r2 버전으로 고친다.

공식 연동 근거:
- https://developers.portone.io/opi/ko/integration/pg/v2/kicc-v2-domestic?v=v2
- https://developers.portone.io/opi/ko/integration/pg/v2/nice-v2?v=v2

배포 결과는 작업 완료 후 추가한다. 운영 API 프로필이 검증되지 않은 상태에서 원격 DB/API나 일반 판매를 활성화하지 않는다.

## 로컬 검증

- 전체 작업공간 빌드 12개 및 타입 검사 20개 통과. 공개 웹 모바일/데스크톱 브라우저 2개, 공통 심사·복구·공개 웹 회귀 48개, config 41개, 계약 26개, 도메인 4개 및 storefront 8개 통과.
- 새로운 일회용 PostgreSQL 17 DB에 변경하지 않은 기존 이력과 0100을 합친 마이그레이션 101개를 적용했다. 새 정책 해시와 과거 문서 보존, 역할별 DB 검사 170개가 빠짐없이 통과했다.
- PortOne NICE/KICC 및 보존된 Toss TEST 결제의 합성 HTTP 응답으로 구매 횟수 주문, 결제 검증, 뽑기 권리 발급, 포함 상품 지급·동일 요청 재시도, 채널 혼합 거절을 검증했다. 실제 PG 창/승인·취소 증거는 아니다.
- 최초 인증 통합 fixture가 구형 2026-10-07 동의 버전으로 고정되어 재동의 오류를 반환했다. 현재 DB 정책을 조회하는 시험으로 수정하고 제한 runtime 역할 인증 검사를 통과했다. 실제 인증·동의 검증은 완화하지 않았다.
- 같은 날짜에 게시한 직접 구매 정책과 구분하기 위해 정책 식별자 `2026-10-13-r2`를 사용한다. 기존 날짜 형식도 유지하며 DB·계약·동의 입력·웹 탈퇴 경로가 같은 형식을 처리하도록 맞췄다. 웹 탈퇴 회귀도 새 식별자로 확인했다. Worker에서 비심사 경로는 이 동의 버전 검사 외에 수정하지 않았다.

원격 API·DB·결제 채널과 실제 signed iPhone/Android 배포는 별도다. 사용자 요청으로 공개 웹과 심사 주소를 갱신하며, 실제 게시 ID/bytes 확인은 아래에 기록한다.

- 최종 웹/앱 구조 검사 1,203개와 API 전체 434개(인증/제한 runtime 역할 포함)가 빠짐없이 통과했다. 새 일회용 DB 101개 마이그레이션과 DB 전체 170개 검사도 통과했다. 정책·재고·거래를 보존하는 복원이며 실제 결제사 승인을 의미하지 않는다.

## 실제 공개 웹 배포

- 사용자 승인 범위에서 Cloudflare Pages `dabboba` Production에 배포했다. 소스 `4cdbc2a3d7af276976029b8c524fa1317fc985c1`, 배포 `47a0b57f-6117-4ca7-9663-7031db0ef426`, 실제 주소 https://dabboba.net/review/ .
- 실제 도메인의 심사 HTML/스크립트/안내·홈페이지·세 정책 문서 총 9개 파일이 빌드 원본과 일치한다. 심사 CSP는 PortOne SDK와 EasyPay/NICE 결제 요청만 허용하며 Toss SDK를 제거했다. no-referrer도 확인했다.
- 브라우저에서 포함 상품 중 1개 지급, 개별 상품 지정 불가, 중복 가능성, 쿠지 준비 중, 이지페이·나이스페이 포트원 준비 안내를 확인했다. 심사 상품 3개와 각각의 실제 포함 구성·공개 확률 조회가 동작한다. 카드 입력·실제 결제는 하지 않았다.
- 원격 심사 서버는 이전 TEST 설정과 필수 약관 2026-09-30이다. 새 NICE/KICC 채널 및 새 API·정책 동의 버전은 미연결이다. 운영 서버는 PRELAUNCH, 필수 약관 2026-10-07을 유지한다. 공개 HTML 게시와 원격 API/DB·서명 앱 반영을 완료로 혼동하지 않는다. 기존 검증된 운영 Edge 프로필 미복구와 실제 채널 미설정은 남은 제한이다.
- 게시 전후 공개 파일과 화면 증거는 Git 바깥 `.dabboba-launch/evidence/included-product-production-20261013/`에 보관한다. 후속 배포 기록 커밋은 문서만 수정한다.

## CI 중복 실행 수정

코드 커밋의 GitHub 실행 `38415135078`은 Workspace/Cloud Run이 통과했으며, DB 단계는 실제 실패한 시험 없이 마지막 skip 수집에서 차단됐다. 새 DB에서 따로 통과한 보관 정책 시험이 전체 worker 목록에 다시 포함되어 의도대로 1회 skip된 것이 원인이다. 신선한 DB 전용 실행에는 TAP와 무skip 검사를 추가하고, 후속 worker 실행에는 이미 통과한 정확한 시험명 하나만 허용했다. 로컬에서도 fresh DB 101개 마이그레이션과 해당 시험 1개·무skip 검사, worker 178개 통과 및 의도된 중복 skip 1개 검사를 확인했다. 다른 skip이나 시험 실패는 여전히 차단한다.
