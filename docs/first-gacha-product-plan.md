# 첫 정식 출시 가챠 등록 기준

2026-09-27 사용자는 아래 구성품을 **각 10개 이상 실제 보유**하고 있다고 확인했으며, 첫 판매 등록 수량은 각 10개로 지정했다. 따라서 이 수량은 임시 예시가 아닌 운영 등록 목표다. 다만 실물 입고 원장과 운영 관리자 API의 등록 결과는 별도로 대조해야 하며, 문서 변경 자체를 운영 재고 반영으로 간주하지 않는다.

- 판매 상품: `gacha-demon-slayer-onemutan-13` — 귀멸의 칼날 오네무탄 13형
- 현재 운영 상태: 판매 상태 `COMING_SOON`, DB 판매 재고 `100`, 공개 확률표 v1은 구성품마다 `20`개(총 `100`). 사전오픈 공개 API가 표시하는 가용 재고 `0`은 실제 DB 재고가 아니다. 결제는 차단돼 있다. 등록 목표는 `ON_SALE`이며 기존 상태를 그대로 유지하려는 결정이 아니다.
- 현재 등록 가격: 5,900원. 관리자 등록 시 판매 가격으로 재확인한다.
- 이미지 근거: `상품사진/가챠/400엔/귀멸의 칼날 오네무탄 13형/`

운영 DB에는 경품 전용 SKU 5개가 이미 있다. 운영 등록 순서는 판매 상품 재고를 관리자 재고 조정 원장으로 `100 → 50` 반영한 뒤, **기존 ACTIVE v1의 20개씩을 그대로 재사용하지 않고** 각 10개의 새 추첨 버전을 작성·공개하고 `ON_SALE`로 전환하는 것이다. 가챠 확률은 기본 가중치와 남은 수량을 함께 사용한다. 5종에 같은 가중치 1을 설정하면 최초 각 20%이지만 판매로 잔여 수량이 달라지면 확률도 달라진다. 확률표의 공개 결과와 사진, 가격, 재고 수량을 실제 앱에서 확인한 뒤 결제 기능을 열어야 한다. 홍보 전이라는 이유로 공개 접속이나 주문 가능성을 0으로 가정하지 않는다.
