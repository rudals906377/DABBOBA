# DABBOBA 상품 상세·사진 등록 검증

## 적용 범위

- 가챠·쿠지 상세에는 포함 상품 목록과 `전체 상품 / 오픈 상품` 집계가 표시된다. 오픈 수량은 서버에 확정된 뽑기 결과를 센다.
- 고객 상세 화면은 상세상품별 실제 수량·확률표를 표시하지 않는다. `50/202`는 수량 비례 규칙을 설명하는 예시이며, 해당 상품의 실제 수치인 것처럼 표시하지 않는다.
- 가챠 추첨은 현재 남은 상세상품 수량에 비례한다. 관리자 가챠 초안은 전체 수량을 후보 상품에 자동 배분하며, 운영자가 상세상품별 수량을 직접 입력하지 않아도 된다. 실제 구성은 관리자가 공개 전에 확인해야 한다.
- 판매 중 상품의 포함 목록은 현재 공개된 추첨 버전의 경품 스냅샷에서 가져온다. 판매 예정 상품의 목록은 준비 중인 활성 상품을 보여준다.
- 관리자 상품 사진 등록은 원본 선택 → 비율·확대·위치 조절 → 잘라낸 결과 적용 → 업로드 순서다. 대표 사진은 6:5·4:3·1:1, 가챠 목록은 1:1, 쿠지 목록은 16:9를 지원한다. 자르기 적용 전에는 업로드할 수 없다. 고객 앱은 원본 사진을 강제로 잘라 보이지 않는다.

## 로컬 확인

- 관리자 테스트 49개와 Next.js 프로덕션 빌드 통과.
- 로컬 브라우저에서 사진 선택, 1:1 비율 변경, 확대, 자르기 적용 후 업로드 버튼 활성화, 비율 재변경 후 버튼 비활성화 확인. 실제 상품 업로드는 하지 않았다.
- API 전체 테스트 271개 통과, 33개는 통합 DB가 없어 건너뜀. 루트 단위 테스트 909개 통과. 웹·관리자 빌드 및 iOS·Android PRELAUNCH 번들 검사 통과.
- 2026-09-29 추가 문구 수정 후 사진·상품 상세 집중 테스트 23개, 모바일 타입 검사, 관리자 프로덕션 빌드와 PR #9의 CI 4개가 모두 통과했다.

## 2026-09-29 운영 읽기 전용 대조

- 로컬 `재고상황/가챠/재고상황.hwp`의 8개 판매 상품명·가격은 운영 공개 카탈로그의 8개 가챠 판매 상품과 일치한다. 이 문서는 합계 392개를 기록하지만, 공개 API는 PRELAUNCH와 `COMING_SOON` 상태에서 재고를 숨겨 `0`으로 응답한다. 따라서 공개 응답은 실제 DB 재고나 물리 재고의 검증 근거가 아니다.
- 8개 상품의 포함 목록 API는 모두 정상 응답했다. 문서·상품 메타데이터의 종류 수 합계 46개와 응답 항목 46개가 맞고, 46개 항목에 이미지 URL이 있다. URL 존재는 실제 파일 내용이나 각 상품의 판매 가능 상태를 증명하지 않는다.
- 먼작귀 모니터 컵케이크 7종과 산리오 캔 속 피규어 5종은 원본 파일명이 숫자여서 포함 상품명이 `1번 구성` 등으로 등록돼 있다. 공개 전에 정확한 명칭을 확인해야 한다.
- PR #9는 아직 열려 있으며 이 작업의 API·관리자·모바일 화면이 운영에 반영됐다고 판정할 수 없다. 운영 상품이 판매 중이 아니므로 실제 상품 상세의 `전체/오픈` 수치와 결제 후 결과는 아직 종단 간 확인하지 못했다.

## 출시 전 확인할 차이와 한계

- 참고 앱의 특정 상품 이미지·문구·배송비·반품 조건을 복제하지 않았다. DABBOBA의 실제 상품 정보와 운영 정책만 표시한다.
- 현재 운영 PRELAUNCH 차단은 유지된다. 로컬 빌드·테스트 통과는 운영 배포, 실제 결제, 상품 사진 업로드, LIVE 집계 표시의 증거가 아니다.
- 운영 상품의 확정 상세상품 수량, 실재고, 안내 문구, 관리자 사진은 운영자가 공개 전에 확인해야 한다.
