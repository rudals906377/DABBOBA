# 2026-10-12 확정 운영 규칙과 배포 준비

## 대표가 확정한 내용

- 먼작귀 7종은 `1`~`7`, 산리오 5종은 `1`~`5`로 표시한다. 실제 구성명은 추후 수정한다. 기존 전체 재고 392개와 내부 배분은 바꾸지 않는다.
- 출고·문의·오배송·파손·환불 요청 담당은 대표. 상담시간 월~금 09:00~17:00, 주말·공휴일 휴무.
- 기본 보관기간 60일. D-7, D-3에 보관 만료 알림. 만료 후 가챠 기준금액 50%, 쿠지 15%를 앱 포인트로 자동 환급한다. 기준금액은 상세 상품 가격이고 해당 1회 뽑기 가격과 같게 등록한다. 상품마다 1P 미만 버림.
- 외부 푸시는 보관 만료 안내만 제공한다. 주문·결제·배송은 앱 내 내역에서 확인한다.
- 심사·결제·필수 검증이 모두 끝나면 바로 공개한다. 미충족 조건을 무시하고 LIVE로 전환한다는 뜻은 아니다.
- 쿠지는 첫 출시에서 제외한다. 15%는 향후 쿠지의 **보관 만료 처리**를 위한 구현이며 쿠지 판매나 선택형 환급 버튼을 이번에 열지 않는다.

## 구현 범위

- `0093`: 새 정책 동의 후 획득한 상품에 가격·환급률을 고정 기록. 이전 상품 소급 전환 없음. 만료 포인트 원장은 상품당 1행, 변경·삭제 불가.
- `0094`: 약관·개인정보처리방침 새 버전 `2026-10-12`, HTML 해시와 회원 재동의. 과거 마이그레이션·게시 증거 보존.
- `0095`: 임시 숫자 이름과 8종 가챠 경품의 기준가격 정렬. 재고·이미지·확률표는 변경하지 않음.
- Worker: 만료 홀드 → 적격 상품 포인트 원장·잔액·최종 상태·알림을 한 트랜잭션으로 처리. 중복 작업은 추가 적립 없음. 배송·매칭 진행 중 상품은 제외. 출처 결제가 확인 중이면 보류. 가격 누락·0P·잔액 한도 초과도 보류하며 자동 폐기 없음.
- 교환받은 상품도 새 정책 가격·환급률 기록은 유지하고 현재 소유자에게 만료 포인트 지급. 기존 교환 완료 후 최소 14일 보장과 60일 기본 기간 유지.
- 앱: 보관·환급·알림 안내와 고객센터 운영시간 반영. 선택형 수동 환급은 기존 가챠 적격 조건을 유지한다.
- 푸시: 신규 발송과 재시도 모두 D-7/D-3 보관 만료 알림만 허용. 나머지 이벤트는 앱 알림함에 보존. 늦은 worker 실행은 이미 지난 D-7 알림과 D-3 알림을 한꺼번에 보내지 않고 가장 가까운 남은 단계만 보냄.

## 배포 전 남은 절차

1. 코드 리뷰·커밋 후, 완성된 **운영 전용 설정**으로 API/admin/worker 배포 준비. 시험 서버 설정을 운영에 재사용하지 않는다.
2. 기존 사용자 대상 공지·약관 적용일 검토 후, 새 HTML과 `0093`~`0095`를 승인된 배포 순서로 함께 적용. 기존 회원에게 재동의, 과거 보관 상품 소급 처리 금지. 현재 파일의 날짜는 준비 버전이며 배포가 늦어지면 적용일·버전·트리거 기준·해시를 묶어서 조정한다.
3. 운영 푸시 자격증명과 iOS/Android 실기기 수신 확인. 기기 권한 거부·로그아웃·토큰 변경도 확인한다. 알림 도착을 보장한다고 안내하지 않는다.
4. 위 검증 후 `WORKER_INVENTORY_STORAGE_EXPIRY_MODE=ENABLED`와 운영 스케줄을 명시적으로 적용한다. 현재 기본값은 계속 DISABLED이며 이 작업은 켜지 않았다.
5. 관리자에서 확률표 8종 공개·판매 상태 확인. 상품명 12개는 더 이상 대표 답변 대기 항목이 아니다.
6. PG 운영 승인·결제/취소/환불 실증, 최종 실기기 점검과 스토어 심사 완료 후 바로 공개한다.

정책 문구는 운영 구현에 맞춘 준비본이며 법률 적합성 승인이나 스토어 심사 통과를 의미하지 않는다. 법정 환불·하자 권리는 이번 보관 규칙 변경으로 제한하지 않는다.
